# Chandan Kumar - Portfolio Website

A modern, responsive personal developer portfolio showcasing skills, experience, and projects as a **Java Full Stack Developer**.

## 🌟 Features
- **Atmospheric Storm Animation:** Moving cloudscape with randomized lightning flashes
- **Interactive Smooth Trailing Cursor:** Fluid dual-cursor tracker with element hover scaling
- **Glassmorphism UI:** Built with Tailwind CSS and CSS backdrop-filters
- **Typewriter Effect:** Dynamic headline rotation
- **Interactive Counters:** Scroll-triggered numerical achievements counter
- **AOS (Animate On Scroll):** Smooth element entrance animations
- **Integrated Resume:** One-click CV download
- **Contact Form:** EmailJS & direct mail client fallback

## 🛠️ Built With
- **HTML5 & CSS3**
- **Tailwind CSS**
- **Vanilla JavaScript**
- **Font Awesome 6 & Google Fonts (Outfit)**
- **AOS Library**

## 🚀 Live Deployment
Easily deployed on Vercel, Netlify, or GitHub Pages.
